SARURA — Step 1 Wireframes

Mobile-first sketches for every page in Development Guide section 4. Built with the exact section-5 palette. Rev. 2 (founder review): Kinyarwanda is the default language (RW active in the toggle), dashboards use 5 bottom tabs + a More sheet, locations follow Rwanda's province → district → sector structure, farmer verification uses named levels, admin has its own dashboard UI, and accounts can be farmer + buyer at once. English labels shown here; the real site is Kinyarwanda-first (see docs/step1-translations.md).

Tokens: font Inter (system fallback) · body ≥16px on the real site (reduced here to fit phone mockups) · buttons ≥44px tall · radius 8–12px · one primary green button per screen · statuses always as word + color, never color alone · all main text colors pass 4.5:1 on white (re-check with a contrast checker before release, per guide section 5).

1. Public pages

No login needed. Header links: Marketplace, How It Works, Sell on SARURA, Login/Register.

2. Buyer dashboard (after login)

Bottom tabs: Home, Requests, Orders, Messages, More. The More sheet holds Saved products, Profile, Language, Help & Contact, Log out — so every section is reachable on small screens (founder review).

3. Farmer dashboard (after login)

Bottom tabs: Home, My products, Requests, Orders, More. The More sheet holds Messages (unread badge), Add product, Saved products, Profile, Language, Log out.

4. Admin dashboard (SARURA's own UI — founder review)

A staff-only React admin area (English-first, 2FA required), with its own UI for the daily work: overview statistics, farmer verification queue, listing moderation, user management, reports, contact-message inbox and the audit log. Django's built-in admin stays on a non-obvious URL for deep back-office tasks only. Every action below writes to audit_logs.

Desktop and tablet layouts expand these same components (product grid 2–4 columns, dashboard tabs become a sidebar). All wireframes respect: one primary button per screen, units next to every number, statuses as words, 44px tap targets, and the green/white/gray palette with amber = pending and red = errors only.
