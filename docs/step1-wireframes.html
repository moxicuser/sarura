SARURA — Step 1 Wireframes

Mobile-first sketches for every page in Development Guide section 4. Built with the exact section-5 palette. Labels are in English here; the real site is Kinyarwanda-first with an EN/RW toggle (see docs/step1-translations.md).

Primary green#247A45 — buttons, links, brand
Dark green#185C35 — header/footer, hover
Light green#E8F5E9 — badges, soft blocks
White#FFFFFF — page & cards (~60%)
Section gray#F4F6F4 — section background
Border gray#DCE3DD — borders, dividers
Medium gray#5F6B63 — secondary text
Dark gray#24332B — text, headings
Red#DC2626 — errors & danger only
Amber#B45309 — pending status only (always with a word)
Tokens: font Inter (system fallback) · body ≥16px on the real site (reduced here to fit phone mockups) · buttons ≥44px tall · radius 8–12px · one primary green button per screen · statuses always as word + color, never color alone · all main text colors pass 4.5:1 on white (re-check with a contrast checker before release, per guide section 5).

1. Public pages

No login needed. Header links: Marketplace, How It Works, Sell on SARURA, Login/Register.

2. Buyer dashboard (after login)

Sections: Overview, My requests, My orders, Messages, Saved products, Profile. Bottom tab bar on phones.

3. Farmer dashboard (after login)

Sections: Overview, My products, Add product, Requests received, Orders, Messages, Profile.

4. Admin

Django's built-in admin, customized, on a non-obvious URL (guide section 4). Not wireframed as React pages. Screens: farmer verification queue, listings (hide/restore), users (ban), reports, contact messages, categories, statistics. All admin actions write to audit_logs; admins read a conversation only for a report or security issue, and each access is logged.

Desktop and tablet layouts expand these same components (product grid 2–4 columns, dashboard tabs become a sidebar). All wireframes respect: one primary button per screen, units next to every number, statuses as words, 44px tap targets, and the green/white/gray palette with amber = pending and red = errors only.
